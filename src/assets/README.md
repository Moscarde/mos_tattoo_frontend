# Assets

Esta pasta contém os recursos estáticos da aplicação.

## Logo

Adicione o arquivo `logo.png` nesta pasta.

**Especificações recomendadas:**
- Formato: PNG com fundo transparente
- Dimensões: 200x60px (ou proporção similar)
- Tamanho: < 100KB

O logo será exibido na barra de navegação superior (navbar) com altura de 60px.

- Ícones

- Etc.
